Transparência técnica

  • Câmbio (USD/BRL, EUR/BRL): fonte 1 — Frankfurter API (taxas de referência do BCE), gratuita e sem chave. Se indisponível, fonte 2 (fallback automático) — AwesomeAPI (câmbio comercial brasileiro), também gratuita e sem chave. O card indica qual das duas respondeu.
  • Ouro, Prata, Platina, Paládio, Cobre: fonte 1 — MetalpriceAPI, só quando há chave paga configurada em "Configurações". Se não houver chave, ou a MetalpriceAPI falhar/não retornar o símbolo, fonte 2 (fallback automático) — Gold-API, gratuita e sem chave.
  • Níquel, Cobalto, Molibdênio: preço à vista via MetalpriceAPI — exigem plano pago dessa API. Cole sua chave em "Configurações"; sem plano pago, o card mostra o erro exato da API em vez de um número inventado.
  • Aço Inox (tonelada), HRC Steel: HRC Steel — fonte 1: Trading Economics via API, só com chave paga configurada em "Configurações"; sem chave (ou se a API falhar), fonte 3/último recurso — extração automática da meta description da própria página pública da Trading Economics, via um proxy CORS de terceiro (allorigins.win). Essa extração é instável por natureza: o proxy pode cair, ou a Trading Economics pode mudar o HTML da página sem aviso — quando isso acontece, o card volta a mostrar "indisponível" com o erro exato, nunca um número inventado. O card sempre indica qual das duas fontes respondeu. Aço Inox não tem, até o momento, nenhuma API ou página pública com dado de mercado confiável identificada (pesquisamos SunSirs, Metals-API, Trading Economics e Argus); o card mostra "sem fonte disponível".
  • Enxofre, Ácido Sulfúrico, Soda Cáustica: Enxofre segue a mesma ordem de 3 fontes do HRC Steel acima (API paga da Trading Economics → extração da página pública via proxy). Ácido Sulfúrico e Soda Cáustica não têm API nem página pública com dado de mercado identificada — os dados existentes (SunSirs, Intratec, ICIS) são publicados apenas em relatórios pagos, sem endpoint ou página acessível; os cards mostram "sem fonte disponível".
  • IGP-M, IPCA, Selic: dados oficiais e históricos completos via Sistema Gerenciador de Séries Temporais do Banco Central (SGS/BCB), pública e sem chave. IGP-M e IPCA exibidos como variação acumulada em 12 meses; Selic como meta definida pelo Copom.
  • Bitcoin, Ethereum: fonte 1 — CoinGecko. Se indisponível, fonte 2 (fallback) — Binance (preço convertido para BRL pela cotação do dólar do dia).
  • Notícias recentes: busca ao vivo via GDELT Project, pública e sem chave.
  • Sempre que existe mais de uma fonte para um ativo, a página tenta a primeira e só usa a segunda se a primeira falhar — nunca combina as duas nem prioriza por preferência arbitrária. Histórico e variação diária não estão disponíveis gratuitamente para a maioria dos metais e químicos — só para câmbio, índices do BCB e cripto. Nenhum dado nesta página é simulado; se uma fonte falhar (ou não existir), o ativo mostra "indisponível" ou "sem fonte disponível" com o motivo técnico exato — nunca um número inventado.

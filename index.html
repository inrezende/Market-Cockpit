Transparência técnica

  • Câmbio (USD/BRL, EUR/BRL): dados reais e históricos completos via Frankfurter API (taxas de referência do BCE). Gratuita, sem chave, sem limite de uso. USD/BRL é calculado por taxa cruzada a partir de EUR (BRL/EUR ÷ USD/EUR).
  • Ouro, Prata, Platina, Paládio, Cobre: preço à vista em tempo real via Gold-API, gratuita e sem chave.
  • Níquel, Cobalto, Molibdênio: preço à vista via MetalpriceAPI — exigem plano pago dessa API (confirmado: não fazem parte do plano gratuito). Cole sua chave em "Configurações" (ícone de engrenagem); sem plano pago, o card mostra o erro exato da API em vez de um número inventado. Unidade conforme padrão da API (onça troy) — para cotações LME por tonelada, consulte a fonte diretamente.
  • Bitcoin, Ethereum: preço, variação 24h e histórico completo via CoinGecko, pública e sem chave.
  • Notícias recentes: busca ao vivo via GDELT Project (monitoramento global de imprensa), pública e sem chave.
  • Histórico e variação diária não estão disponíveis gratuitamente para os 8 metais — só para câmbio e cripto. Nenhum dado nesta página é simulado; se uma fonte falhar, o ativo correspondente mostra "indisponível" com o motivo técnico (nunca um número inventado).
